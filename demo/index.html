Quay Chat

Drop-in site chat

Open the bubble in the corner. This page fakes the backend so you can send, reply, and react without setting up Slack or Telegram.

GitHub

Built by Ali Al-Janabi. When you ship, point endpoint at your own adapter.

Install 
npm i @aligfx/quay
Usage 
import { createQuay } from "@aligfx/quay";
import "@aligfx/quay/style.css";

createQuay({
  endpoint: "https://your-adapter.example",
  title: "Support",
});
Script tag 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@aligfx/quay/dist/quay.css" />
<script src="https://cdn.jsdelivr.net/npm/@aligfx/quay/dist/quay.iife.js"></script>
<script>
  Quay.init({
    endpoint: "https://your-adapter.example",
    title: "Support",
  });
</script>
